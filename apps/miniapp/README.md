# Miniapp

This directory is reserved for a mini program frontend, such as WeChat Mini
Program, Alipay Mini Program, or a Taro/uni-app based miniapp.

The starter keeps this sample dependency-free so the repository works out of
the box. Downstream products can replace `src/main.ts` with their real miniapp
framework entry point while keeping the same source-of-truth docs, contracts,
and quality gates.

## Commands

From the repository root:

```bash
make miniapp-build
make ts-test
```
